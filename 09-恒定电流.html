电流与微观表达式

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电流强度 I=Δq/Δt，描述单位时间内通过导体横截面的电荷量；电流方向规定为正电荷定向移动方向。
  • 金属中真正定向移动的是自由电子，因此电子定向移动方向与电流方向相反。
  • 恒定电流中，同一串联通路各处电流相等，本质是电荷守恒：导体中不会持续堆积电荷。
  • 微观表达式 I=nqSv，其中 n 为单位体积载流子数、q 为单个载流子电荷量、S 为横截面积、v 为定向移动速率。
  • 电子热运动速率很大，但宏观电流只由定向移动的平均效果决定，不可把热运动速率代入公式。

拓展与模型

  • 同种材料、同温度的串联导线中 n、q 相同，因此 Sv 相同：横截面越小，定向移动速率越大。
  • 若材料不同，必须把 n 的变化一起带入 nqSv，不能只比较横截面积。
  • 电流大小由单位时间通过截面的净电荷量决定，不由导体电阻直接定义。
易错提醒
把电子运动方向当成电流方向；或者看到粗细不同的串联导线就误判电流不同。

电流与微观表达式

少而精：一道题覆盖本模块最关键的迁移能力
高考中档 · 精选一题
两段不同材料导线 A、B 串联，单位体积自由电子数之比 nA:nB=2:1，横截面积之比 SA:SB=1:3。稳定后求电子定向移动速率之比 vA:vB。若 20 s 内通过 A 截面的电荷量为 40 C，求电路电流。
串联稳态电流相等：nAeSAvA=nBeSBvB，所以 vA/vB=(nBSB)/(nASA)=3/2。又 I=q/t=40/20=2 A。

欧姆定律、伏安特性与电阻

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电阻定义 R=U/I。对给定状态的元件，U 与 I 的比值反映该状态下的电阻。
  • 欧姆定律适用于温度等条件基本不变的线性导体；并非所有元件的 U、I 都成正比。
  • I-U 图像中，定值电阻是一条过原点直线，斜率 I/U=1/R；若画 U-I 图像，则斜率为 R。
  • 小灯泡等非线性元件的伏安特性曲线通常弯曲，往往与温度变化导致电阻变化有关。
  • 串联同电流、分压；并联同电压、分流。复杂电路先做等效，再回到局部量。

拓展与模型

  • 非线性元件在某工作点的电阻仍用 R=U/I，不能把曲线切线斜率直接当作高中语境下的电阻。
  • 判断灯泡亮度，本质上比较实际电功率，而不是只比较电流或电压。
  • 元件接入电源后的实际工作状态由电源约束与元件伏安特性共同决定。
易错提醒
I-U 与 U-I 图像的斜率含义混淆；把小灯泡误当成定值电阻。

电阻定律与导体形变

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电阻定律 R=ρL/S，其中 ρ 由材料和温度决定，L 为长度，S 为横截面积。
  • 同种材料、温度不变时，电阻与长度成正比、与横截面积成反比。
  • 均匀导线被拉伸时常用体积不变 LS=常量。若长度变为 λL，则截面积变为 S/λ，电阻变为 λ²R。
  • 金属导体温度升高时电阻率通常增大，因此明显升温时不能机械套用阻值不变。
  • 涉及切割、并联时，先分别求每一段的新电阻，再做串并联等效。

拓展与模型

  • 长度和横截面积常同时变化，最稳的方法是联立 R=ρL/S 与体积约束。
  • 同一根导线拉伸后再切割，等效电阻可能出现反直觉结果，必须按步骤处理。
  • 恒压时 P=U²/R，恒流时 P=I²R，结论方向相反。
易错提醒
只把长度乘上倍数，却忘了体积不变会导致横截面积同时改变。

电阻定律与导体形变

少而精：一道题覆盖本模块最关键的迁移能力
高考中档 · 精选一题
一根均匀金属导线原电阻为 R。将它均匀拉长到原来的 2 倍，认为体积和电阻率不变；随后从中点剪成两等段，再把两段并联。求最终等效电阻与原电阻的关系。
拉长后 L'=2L、S'=S/2，因此整根电阻 R'=ρ(2L)/(S/2)=4R。剪成两等段后，每段电阻为 2R；两段并联，最终等效电阻为 R。

电源、电动势与闭合电路

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电动势 E=W非/q，描述电源内部非静电力把其他形式能转化为电能的能力。
  • 闭合电路欧姆定律 I=E/(R外+r)，其中 r 为电源内阻。
  • 路端电压 U=E-Ir=IR外。放电时电流越大，内电压 Ir 越大，路端电压越小。
  • 断路极限 I→0 时 U→E；短路时 R外≈0，短路电流 I短=E/r。
  • 复杂外电路也遵循同一主线：先求外电路等效电阻，再求总电流，再回到支路。

拓展与模型

  • 外电阻增大时，总电流减小，但路端电压通常增大，这是有内阻电源的典型特征。
  • 电源内阻与外电阻在总电阻中地位相同，只是内阻上的功率属于电源内耗。
  • 理想电流表电阻视为零，理想电压表电阻视为无穷大。
易错提醒
把路端电压始终当作电动势；忽略内阻后又分析有内阻电源的动态变化。

路端电压—电流图像与工作点

概念 → 规律 → 模型 → 高频误区

核心知识

  • 由 U=E-Ir 可知，电源的 U-I 图像是一条斜率为 -r 的直线。
  • 纵轴截距是电动势 E；横轴截距是短路电流 E/r；斜率绝对值是内阻 r。
  • 对定值负载有 U=IR，电源图线与负载图线的交点就是实际工作点。
  • 非线性负载也可以用“工作点”思想处理：必须同时满足电源约束和负载伏安特性。
  • 工作点可直接读出实际电流、路端电压，再进一步求输出功率、效率与内耗。

拓展与模型

  • 同一电源的 U-I 直线不因外电路变化而改变，改变负载只是在这条直线上移动工作点。
  • 图像交点法本质是联立方程，尤其适合无法直接用 U=IR 描述的非线性元件。
  • 电源效率 η=U/E，可由工作点的路端电压与纵轴截距直接比较。
易错提醒
把 U-I 图像斜率写成 +r；或者把横轴截距当成正常工作电流。

含电容器的直流稳态电路

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电容器接入直流电路并达到稳态后，电容支路没有持续电流，可把该支路视为断路。
  • 虽然稳态支路无电流，但电容器两端仍有电压；其电压由所连接两个节点的电势差决定。
  • 求稳态电容器电荷量时，先去掉电容支路求节点电势，再用 Q=CU。
  • 开关切换题应分别求切换前后的稳态电压，再用 ΔQ=CΔU 求电荷量变化。
  • 若要判断某段导线实际通过的电荷量，还需结合极板正负与电荷流向。

拓展与模型

  • 稳态“断路”只针对持续电流，不代表电容器不存在或其两端电压为零。
  • 电容器可以跨接在不相邻节点之间，画出节点电势关系比机械识别串并联更可靠。
  • 含电容器的开关题往往是两个稳态电路之间的比较题。
易错提醒
看到电容器就把整条电路断开；或者把电容器电压误认为一定等于电源电动势。

电路动态分析与串并联功率

概念 → 规律 → 模型 → 高频误区

核心知识

  • 动态电路分析的第一步是判断外电路等效电阻如何变化，再判断总电流与路端电压。
  • 对有内阻电源：R外增大 → I总减小 → 内电压 Ir减小 → 路端电压 U增大。
  • 局部支路电流必须结合该支路两端电压和支路电阻判断，不能只跟随总电流变化。
  • 功率常用 P=UI=I²R=U²/R；串联同电流时功率与 R 成正比，并联同电压时功率与 1/R 成正比。
  • 灯泡亮度比较最终要落到实际功率，而不是只看电流表或电压表某一个读数。

拓展与模型

  • “串反并同”可以作为快速提示，但不能代替完整的电路结构判断。
  • 某一并联支路电阻增大时，另一支路两端电压可能上升，因此其电流反而可能增大。
  • 功率变化有时与电流变化方向不同，因为 P 同时受 U 和 I 影响。
易错提醒
看到总电流减小，就直接断言所有支路电流都减小。

电动机与非纯电阻电路

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电动机正常工作时是非纯电阻用电器，不能直接写 I=U/r；线圈电阻 r 只对应焦耳热部分。
  • 输入电功率 P入=UI；线圈热功率 P热=I²r；机械输出功率 P机=UI-I²r。
  • 若用反电动势描述，则 U=E反+Ir，机械功率可写为 P机=E反I。
  • 正常转动时存在反电动势，使工作电流显著小于 U/r。
  • 堵转时反电动势近似为零，电流接近 U/r，容易产生很大的热功率。

拓展与模型

  • 若忽略其他机械损耗，电动机效率 η=P机/P入。
  • 提升重物、牵引车辆等题目，可把机械输出功率与 mgv、Fv 联立。
  • “正常工作电流”和“堵转电流”的明显差异是非纯电阻模型的核心。
易错提醒
把电动机线圈电阻直接代入 I=U/r 去求正常工作电流。

电源的功率、内耗与效率

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电源总功率 P总=EI，表示电源把其他形式能转化为电能的速率。
  • 内耗功率 P内=I²r；输出功率 P出=UI=I²R外。
  • 能量关系为 P总=P出+P内。
  • 电源效率 η=P出/P总=U/E=R/(R+r)。
  • 随着外电阻 R 增大，效率单调增大，但输出功率并不单调增大。

拓展与模型

  • 效率高不等于输出功率大；当 R≫r 时效率接近 100%，但电流很小，输出功率反而趋近于 0。
  • R=r 时输出功率最大，但此时效率恰为 50%。
  • 题目问“效率最优”和问“向负载输送最大功率”是两类不同优化目标。
易错提醒
把“效率最大”和“输出功率最大”误认为同一个条件。

最大输出功率与同功率双解

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电源向纯电阻负载输出功率 P=E²R/(R+r)²。
  • 当 R=r 时输出功率最大，Pmax=E²/(4r)。
  • P-R 图像在 R=r 左右往往存在同一功率对应两个不同负载的情况。
  • 若 R1、R2 对应相同输出功率，则常有 R1R2=r²。
  • 同功率的两个工作状态效率一般不同：R 较大的那一个效率更高、电流更小。

拓展与模型

  • 可以用配方法、均值不等式或函数思想得到 R=r 的极值结论。
  • 同功率双解题常与效率、路端电压、电流比较结合。
  • 最大功率结论的前提是电源 E、r 不变且外电路可等效为可调纯电阻。
易错提醒
看到“最大”就直接写 R=r，却没有确认题目最大的是输出功率，而不是效率或某个局部电阻功率。

电学实验基础与实物连接

概念 → 规律 → 模型 → 高频误区

核心知识

  • 电学实验首先看清三类元件：电源、保护元件（如滑动变阻器）、测量元件（电流表、电压表）。
  • 连接原则：电流表串联接入、电压表并联接入，且必须让电流从表头正接线柱流入。
  • 闭合开关前应使滑动变阻器处于保护状态：限流式取最大阻值，分压式取使待测部分电压最小的一端。
  • 实物图连线时可先抓主回路，再接表头支路，最后检查短路与断路。
  • 实验读数、量程、分度值与有效数字同样属于考点，不能只会套公式。

拓展与模型

  • “先主后支、先串后并、先保护后测量”是实物连线最稳定的操作顺序。
  • 若存在滑动变阻器，必须明确它在电路中的任务：保护、调节还是获得尽可能宽的测量范围。
  • 实验题常把实物连接、错误改正、读数和原理判断综合在同一题目中。
易错提醒
电流表并联、电压表串联；或闭合开关前未把滑动变阻器调到保护位置。

电表改装：量程扩展与原理

概念 → 规律 → 模型 → 高频误区

核心知识

  • 表头本质是小量程电流表，其满偏电流记为 Ig，内阻记为 Rg。
  • 把表头改装成电压表时，应串联分压电阻 R串，使总量程满足 U=Ig(Rg+R串)。
  • 把表头改装成大量程电流表时，应并联分流电阻 R并，使额定总电流 I 满足 IgRg=(I-Ig)R并。
  • 改装的核心思想是：表头永远只允许通过满偏电流 Ig。
  • 若题目给出表头偏转到某一刻度位置，通常意味着通过表头的电流与偏角成正比。

拓展与模型

  • 改装后新表的内阻会发生显著变化：电压表内阻变大，电流表内阻变小。
  • 同一表头既可改为电流表又可改为电压表，关键在于附加电阻是串联还是并联。
  • 高考题常把表头改装与电路动态、量程选择、校准误差放在一起综合考查。
易错提醒
改装电压表时误把附加电阻并联；改装电流表时误把分流电阻串联。

偏角、量程与校准误差

概念 → 规律 → 模型 → 高频误区

核心知识

  • 理想表头中，偏角与通过表头的电流成正比，因此偏角本质上反映了表头电流大小。
  • 改装表如果附加电阻取值不准、导线接触不良或表头内阻变化，都会引起量程误差和读数误差。
  • 校准问题常通过“实际满偏值”和“刻度标称值”的比较来判断偏大偏小。
  • 若并联分流电阻偏大，则分流减弱，表头电流偏大，实际量程往往偏小；串联分压电阻偏大，则实际量程偏大。
  • 分析量程和偏角问题时，最稳的方法仍然是列出表头支路与附加电阻支路的电流电压关系。

拓展与模型

  • “刻度盘不改、只改电路”的本质是让原来的刻度位置对应新的被测物理量。
  • 误差分析一般先判断某个附加电阻变化后，表头在同一被测量下偏转变大还是变小，再判断读数偏大偏小。
  • 很多偏角问题都可化归为“同一偏角对应的表头电流是否仍是设计值”。
易错提醒
把“实际量程偏大/偏小”和“读数偏大/偏小”混为一谈。

伏安法测电阻：内外接与误差分析

概念 → 规律 → 模型 → 高频误区

核心知识

  • 伏安法测电阻有电流表内接与外接两种基本接法。
  • 内接法中，电压表测得的是待测电阻与电流表的总电压，测得电阻偏大，适合测大电阻。
  • 外接法中，电流表测得的是待测电阻与电压表支路总电流，测得电阻偏小，适合测小电阻。
  • 口诀“内大外小”本质来自系统误差方向：内接偏大、外接偏小。
  • 选择内外接时，可通过比较待测电阻与电流表内阻、电压表内阻的数量级，或用临界公式判断。

拓展与模型

  • 高考中更重要的是会说明误差来源：到底是哪只表把“不该测的量”一并测进去了。
  • 若题目给的是图像法求电阻，内外接误差会体现在斜率上。
  • 测小电阻更怕电流表分压影响，测大电阻更怕电压表分流影响。
易错提醒
只会背“内大外小”，却说不清误差来源，也不会根据阻值范围选择接法。

滑动变阻器：限流式与分压式

概念 → 规律 → 模型 → 高频误区

核心知识

  • 滑动变阻器有两类常用接法：限流式和分压式。
  • 限流式结构简单、耗能较小，适用于只需小范围调节电流且保护要求不高的情形。
  • 分压式能使待测部分电压从几乎 0 到接近电源电压连续变化，适合小阻值元件或要求测量范围尽量大时使用。
  • 当待测电阻较小、实验要求从 0 附近开始调节或要求获得较多测量点时，通常优先选择分压式。
  • 确定滑片初始位置时，要先满足保护要求，再考虑调节范围。

拓展与模型

  • 限流式本质上是滑动变阻器串联在主回路中；分压式本质上是把滑动变阻器作为可变电势分配器。
  • 选择接法时要同时看：待测电阻大小、滑动变阻器总阻值、是否要求电压从零可调、是否强调保护仪器。
  • 在描绘小灯泡伏安特性曲线等实验中，分压式几乎是默认优选。
易错提醒
只凭器材表机械判断接法，而不结合实验目的；或者把闭合开关前的滑片位置放反。
