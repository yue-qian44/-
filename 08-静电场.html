电荷：守恒、量子化与起电

概念、规律与模型
05/44

核心知识

  • 元电荷 e=1.60×10⁻¹⁹ C，物体带电量必须是元电荷的整数倍。
  • 电荷守恒：孤立系统中电荷总量不变；接触起电只发生电荷重新分配。
  • 感应起电的本质是导体内自由电荷在外电场作用下重新分布，并不凭空产生电荷。
  • 完全相同的金属小球接触后达到等势；常见理想模型中可用总电荷平均分配处理。

解题抓手

先判断是否为孤立系统，再追踪每次接触前后的总电荷；涉及相同金属球时，把“接触—分开”拆成若干独立步骤。

建议顺序：判对象 → 判方向 → 找不变量/临界条件 → 列主方程 → 检查物理意义。

易错警报：场强是矢量，电势是标量；“场强为零”与“电势为零”不能互相推出。

典型题 + 高考中档
06/44

题 1｜典型

三个完全相同的金属小球 A、B、C，初始电荷量分别为 +6q、−2q、0。先让 A 与 C 接触后分开，再让 C 与 B 接触后分开。求最终 A、B、C 的电荷量。
A、C 第一次接触：总电荷为 6q，平均后 A=C=3q。随后 C(3q) 与 B(−2q) 接触，总电荷为 q，平均后 B=C=q/2。最终 A=3q，B=q/2，C=q/2。

题 2｜高考中档

四个完全相同的金属小球 A、B、C、D，初始电荷量依次为 +8Q、−4Q、0、0。按顺序进行：A 与 C 接触分开；B 与 D 接触分开；再让 C 与 D 接触分开。求最终 C、D 的电荷量，并判断系统总电荷是否改变。
A、C 接触后均为 +4Q；B、D 接触后均为 −2Q；C(+4Q) 与 D(−2Q) 再接触，总电荷 +2Q，平均后 C=D=+Q。全过程系统总电荷始终为 +4Q，没有改变。

库仑定律与带电小球平衡

典型题 + 高考中档
08/44

题 1｜典型

两个相同小球质量均为 m、带同种电荷 q，用长度均为 L 的绝缘细线悬于同一点。平衡时两线与竖直方向夹角均为 θ。求 q 的表达式。
对任一小球：Tcosθ=mg，Tsinθ=F库，所以 F库=mg tanθ。两球间距 r=2Lsinθ。由 kq²/r²=mg tanθ，得 q=2Lsinθ·√(mg tanθ/k)。

题 2｜高考中档

A、B 两带正电小球固定在同一直线上，相距 3a，电荷量分别为 Q 和 4Q。现将一个带正电、质量可忽略的试探小球放在线段 AB 上，若只受 A、B 的库仑力，求其平衡位置到 A 的距离。
设平衡点距 A 为 x，则距 B 为 3a−x。两力方向相反且大小相等：kQq/x²=k·4Qq/(3a−x)²。得 3a−x=2x，所以 x=a。

电场强度：定义与点电荷电场

典型题 + 高考中档
10/44

题 1｜典型

真空中一点电荷 Q=−4.0×10⁻⁸ C。距 Q 为 0.30 m 的 P 点放置电荷量 q=+2.0×10⁻⁶ C 的试探电荷。求 P 点场强大小及试探电荷所受电场力大小和方向。
E=k|Q|/r²=9×10⁹×4×10⁻⁸/0.09=4.0×10³ N/C，方向指向负电荷 Q。F=qE=2×10⁻⁶×4×10³=8.0×10⁻³ N，因 q>0，受力方向与 E 相同，也指向 Q。

题 2｜高考中档

质量为 m、带电量 +q 的小球用绝缘细线悬挂在匀强水平电场中，静止时细线与竖直方向夹角为 37°。取 sin37°=0.6，cos37°=0.8。求电场强度 E。
小球受重力 mg、拉力 T、电场力 qE。平衡条件：Tcos37°=mg，Tsin37°=qE。相除得 tan37°=qE/(mg)=0.75，因此 E=0.75mg/q。

电场强度叠加与对称模型

典型题 + 高考中档
12/44

题 1｜典型

正方形 ABCD 边长为 a，A、B、C 三个顶点各固定电荷量为 +Q 的点电荷，D 点无电荷。求正方形中心 O 处的电场强度方向。
若 D 点也放 +Q，则四个顶点对 O 的合场强为 0。因此现有 A、B、C 三个电荷的合场强，等于“D 点电荷单独产生场强”的反方向。D 点正电荷在 O 处场强方向由 D 指向 O，故实际合场强方向由 O 指向 D。

题 2｜高考中档

正六边形六个顶点原本各固定电荷量 +Q 的点电荷，中心 O 合场强为 0。现移去其中一个顶点 A 处的电荷。若六边形边长为 a，求 O 点合场强的大小和方向。
完整六边形对称，中心合场强为 0。移去 A 后，剩余五个电荷的合场强等于 A 点原电荷在 O 处场强的反方向。正六边形中心到顶点距离等于边长 a，所以 E=kQ/a²，方向由 O 指向 A。

电势能与电势

典型题 + 高考中档
14/44

题 1｜典型

在某静电场中 A、B 两点电势分别为 12 V 和 −3 V。将电荷量 q=−2.0×10⁻⁶ C 的粒子从 A 移到 B，求其电势能变化量。
ΔEp=q(φB−φA)=−2×10⁻⁶×(−3−12)=+3.0×10⁻⁵ J。电势能增加 3.0×10⁻⁵ J。

题 2｜高考中档

一带电粒子仅受静电力作用，从 P 点由静止释放后运动到 Q 点，速度逐渐增大。已知 φP>φQ。判断粒子电性，并说明其电势能、动能如何变化。
粒子由高电势 P 运动到低电势 Q，且静电力做正功、动能增大，因此 ΔEp<0。由 ΔEp=q(φQ−φP)，其中 φQ−φP<0，要使 ΔEp<0 必须 q>0。故粒子带正电；电势能减小，动能增大。

电势差、等势面与路径无关

概念、规律与模型
15/44

核心知识

  • UAB=φA−φB；电场力做功 WAB=qUAB。

两组相邻等势面的电势差均为 20 V。在局部近似匀强时，E≈Δφ/Δs。C、D 附近等势面间距更小，所以该处电势变化更快，平均场强更大，即 E_CD>E_AB。

匀强电场中电势差与场强

典型题 + 高考中档
18/44

题 1｜典型

匀强电场方向水平向右，场强 E=200 V/m。A、B 两点连线长 0.50 m，与场强方向夹角 60°，B 在 A 的右侧。求 UAB。
沿场强方向的投影 d=0.50cos60°=0.25 m。沿电场方向电势降低，所以 UAB=φA−φB=Ed=200×0.25=50 V。

题 2｜高考中档

在边长为 a 的正方形 ABCD 中存在匀强电场，已知 φA=30 V、φB=10 V、φD=20 V。求 φC，并判断电场方向在 AB、AD 两边方向上的电势降落率大小关系。
匀强电场中电势是位置的一次函数。沿 A→B 电势降低 20 V，沿 A→D 降低 10 V，因此从 A 到 C 的总降低量为 30 V，φC=0 V。因 AB、AD 长度相同，AB 方向电势降落率为 20/a，AD 为 10/a，故 AB 方向分量更大。

等量同种正点电荷 +Q 固定在 x=±a 处。求原点 O 的场强与电势（零电势取无穷远）。

空间拼接电场与分区运动

典型题 + 高考中档
40/44

题 1｜典型

x<0 区域存在水平向右的匀强电场 E，x>0 区域存在同大小、方向向左的匀强电场 E。正粒子从 x=−L 处由静止释放。忽略其他力，求粒子第一次到达 x=+L 时的速度。
在 x<0 区域，电场力做功 qEL，粒子到 x=0 时动能为 qEL。进入 x>0 后电场力反向做负功，从 0 到 +L 做功 −qEL，恰好把动能减为 0。因此第一次到达 x=+L 时速度为 0。

题 2｜高考中档

正粒子从静止出发，先经长度 L、场强 E 的加速区，再进入长度 2L、场强方向相反但大小仍为 E/2 的减速区。忽略重力。求粒子到达第二电场区末端时的动能，并判断能否穿出。
第一段电场力做功 qEL，故进入第二段时 Ek=qEL。第二段电场力做功 W₂=−q(E/2)·2L=−qEL。末动能为 0，因此粒子恰好到达第二段末端，临界速度为 0。若第二段稍长或场强稍大，则会在区内返回。

时间周期电场与分段运动

典型题 + 高考中档
42/44

题 1｜典型

正粒子初速度为 0，在一维周期电场中运动：前 τ 时间场强为 +E₀，后 τ 时间场强为 −E₀，如此周期重复。令 a=qE₀/m。求一个完整周期 2τ 后粒子的速度和位移。
前 τ：v₁=aτ，x₁=½aτ²。后 τ：加速度 −a，末速度 v₂=0；位移 x₂=aτ·τ−½aτ²=½aτ²。故周期末速度回到 0，总位移为 aτ²。

题 2｜高考中档

在上题周期电场中，粒子连续经历 N 个完整周期。求 N 个周期后的速度和总位移。若 N=5，写出结果。
每个周期末速度都回到 0，因此每周期运动状态在速度上重复，但位置向前平移 aτ²。故 N 周期后 v=0，x_N=Naτ²。N=5 时 x=5aτ²。

叠加电场中的粒子运动

典型题 + 高考中档
44/44

题 1｜典型

正粒子质量 m、电荷量 q，初速度 v₀ 沿 x 轴正方向。空间中同时存在 Eₓ=E₀（向 +x）和 Eᵧ=2E₀（向 +y）的两个匀强电场。写出粒子的加速度分量与 t 时刻速度分量。
aₓ=qE₀/m，aᵧ=2qE₀/m。故 vₓ=v₀+(qE₀/m)t，vᵧ=(2qE₀/m)t。

题 2｜高考中档

一正粒子从坐标原点以初速度 v₀ 沿 +x 方向进入区域。区域内只有竖直向上的匀强电场 E。若区域宽度为 L、高度为 H，要求粒子恰好从右上角 (L,H) 飞出，求 E 应满足的关系。
x 方向匀速：t=L/v₀。y 方向初速度为 0，位移 H=½(qE/m)t²。代入 t 得 H=½(qE/m)(L²/v₀²)，所以 E=2mHv₀²/(qL²)。
