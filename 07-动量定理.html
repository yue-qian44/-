动量（基础课）

第 1 / 3 页

核心知识点

  • 动量定义：p=mv，是矢量，方向与速度方向相同，单位为 kg·m/s。
  • 动量变化量 Δp=p₂-p₁，同一直线问题应先规定正方向，再用正负号运算。
  • 动量是状态量；比较动量时既要看质量和速度大小，也要看速度方向。
  • 速度方向改变即使速率不变，动量仍会发生变化。

解题主线

先明确系统与过程 → 规定正方向 → 选择动量/冲量核心方程 → 联立能量、相对速度或运动学条件。

动量定理和冲量（基础课）

第 1 / 3 页

核心知识点

  • 冲量 I=Ft（恒力情形），是过程量、矢量，方向与力方向一致。
  • 动量定理：合外力的冲量等于物体动量变化量，即 I合=Δp。
  • 变力冲量可由 F-t 图像下的有向面积求得。
  • 应用时先规定正方向，统一处理力、速度和动量的正负号。

下落缓冲问题（题型技巧课）

第 1 / 3 页

核心知识点

  • 缓冲类问题通常分两段：先求接触前速度，再对缓冲阶段用动量定理。
  • 缓冲阶段支持力与重力方向相反，列式时不要漏掉重力冲量。
  • 延长停止时间或增大缓冲距离，都能显著减小平均冲击力。
  • 常见模型包括安全气囊、海绵垫、接球屈臂、跳高垫等。

F-t图像、f=kv（题型技巧课）

第 1 / 3 页

核心知识点

  • F-t 图像与时间轴围成的有向面积表示冲量，正负由力的方向决定。
  • 分段图像题先分别求每段面积，再代入 I合=Δp。
  • 阻力满足 f=kv 时，速度越大阻力越大；竖直下落终端速度满足 mg=kv终。
  • 终端速度出现时合力为 0、加速度为 0，但速度不为 0。

解题主线

先明确系统与过程 → 规定正方向 → 选择动量/冲量核心方程 → 联立能量、相对速度或运动学条件。

水柱冲击问题（题型技巧课）

第 1 / 3 页

核心知识点

  • 流体冲击题核心是“单位时间内流过的质量”与“单位时间内动量变化”。
  • 若水流密度为 ρ、横截面积为 S、速度为 v，则质量流率 ṁ=ρSv。
  • 水流被完全挡停时，平均冲力大小 F=ρSv²。
  • 若水流改变方向，要按矢量计算速度变化，再用 F=Δp/Δt。

解题主线

先明确系统与过程 → 规定正方向 → 选择动量/冲量核心方程 → 联立能量、相对速度或运动学条件。

动量守恒定律-上（基础课）

第 1 / 3 页

核心知识点

  • 系统所受合外力为 0，或外力冲量相对内力冲量可忽略时，系统总动量守恒。
  • 动量守恒是矢量关系：p初=p末；一维问题可用正负号，二维问题需分方向。
  • 内力可很大但不会改变系统总动量，因为内力冲量在系统内部成对抵消。
  • 碰撞、爆炸、反冲等短时过程常满足动量近似守恒。

解题主线

先明确系统与过程 → 规定正方向 → 选择动量/冲量核心方程 → 联立能量、相对速度或运动学条件。

第 1 / 3 页

  • 反冲模型通常初始总动量为 0，分离后各部分动量大小相等、方向相反。

  • 速度必须明确是相对地面的速度还是相对另一物体的速度。

第 1 / 3 页

核心知识点

  • 进阶板块题关键是“相对运动”：a相=a滑块-a木板，v相与s相决定是否滑出。
  • 若摩擦恒定，滑块和木板分别做匀变速运动，可用相对运动公式。
  • “最小板长”通常等于达到共速前的相对位移。
  • 若地面也粗糙或有外力，系统总动量可能不守恒，要改用分物体动力学。

弹簧模型-基础篇（题型技巧课）

第 1 / 3 页

核心知识点

  • 两个物体通过轻弹簧相互作用且水平外力可忽略时，系统动量守恒。
  • 理想弹簧作用过程中，动能与弹性势能相互转化，系统机械能守恒。
  • 弹簧压缩或伸长达到最大时，两物体相对速度为 0，即瞬时同速。
  • 弹簧恢复原长时弹性势能为 0，常对应碰撞式速度交换或分离状态。

解题主线

先明确系统与过程 → 规定正方向 → 选择动量/冲量核心方程 → 联立能量、相对速度或运动学条件。

例题 2｜贴合高考题

题目
质量 m 的小球从可动光滑圆形轨道最低点以对地速度 v₀ 向右运动，轨道质量为 M、初始静止，圆轨道半径为 R，水平面光滑。若要求小球恰好能沿内轨通过最高点，求 v₀ 的最小值。
解答
系统水平动量守恒，质心平动动能恒定。用相对运动能量更简洁：约化质量 μ=mM/(m+M)。最低点相对速度为 v₀；最高点临界相对速度满足 u²=gR。相对动能减少等于重力势能增加 2mgR：1/2μv₀²=1/2μgR+2mgR。解得 v₀²=gR[1+4(m+M)/M]=gR(5+4m/M)，即 v₀,min=√[gR(5+4m/M)]。
