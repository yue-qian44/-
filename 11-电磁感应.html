磁通量、感应条件与楞次定律

知识只为做题服务：先识别模型，再选主方程
5/43

核心知识与题型

  • 磁通量看“穿过回路的有效磁场”：Φ=BS cosθ。B、S、夹角或有效区域发生变化，都可能引起磁通量变化。
  • 闭合回路中产生感应电流的条件是磁通量发生变化；只有磁场存在但磁通量不变，不产生持续感应电流。
  • 楞次定律抓住“阻碍变化”：原磁通量增大，感应磁场反向；原磁通量减小，感应磁场同向。
  • 机械效应常用“来拒去留、增缩减扩”快速判断，但最终仍应回到“阻碍磁通量变化”。
  • 双圈、螺线管—线圈模型中，先判断原线圈磁场方向，再判断磁通量的增减，最后用安培定则确定感应电流。

高频标签

磁通量 Φ=BS cosθ感应电流条件增反减同来拒去留双圈互感

解题抓手

方向题四步：原磁场 → 磁通量增减 → 感应磁场 → 感应电流。遇到运动模型，再用安培力方向检查是否“阻碍相对运动”。
磁通量变化 → 感应电动势 → 电流 → 安培力 → 运动 / 能量

题目 1 · 线圈方向与电流大小
N 匝圆形线圈面积为 S、总电阻为 R，匀强磁场垂直纸面向里，磁感应强度以恒定速率 k 逐渐减小。求感应电流大小并判断方向。
解析
磁通量向里且减小，感应磁场应向里，因此电流为顺时针。E=N·S·k，故 I=NSk/R。
题目 2 · 整体平移是否感应
闭合矩形线圈整体以速度 v 在足够大的匀强磁场中平移，线圈平面始终与磁场垂直，线圈始终完全处在磁场内。判断是否有感应电流，并说明理由。
解析
没有。虽然线圈在运动，但 B、S、夹角均不变，穿过线圈的磁通量不变；也可从各边动生电动势相互抵消理解。

题目 3 · 双圈互感方向
同一平面内有两个同心圆线圈 A、B。A 中电流从观察者一侧看为顺时针且逐渐增大。判断 B 中感应电流方向。
解析
A 在线圈中心产生垂直纸面向里的磁场，且磁通量向里增大。B 要产生向外的感应磁场，所以 B 中感应电流为逆时针。
题目 4 · 金属环接近磁极
闭合金属环沿条形磁铁轴线靠近 N 极。若忽略环的重力，判断环靠近磁铁一侧形成的等效磁极，并说明环受到的轴向作用力方向。
解析
靠近时穿过环的原磁通量增大，感应效应要阻碍靠近，所以环靠近磁铁的一侧形成 N 极，与磁铁 N 极相斥，环受到远离磁铁方向的力。

高中物理｜电磁感应专题强化

法拉第定律、感生电动势与电荷量

知识只为做题服务：先识别模型，再选主方程
8/43

核心知识与题型

  • 法拉第电磁感应定律给出平均感应电动势：E=N|ΔΦ|/Δt；若磁通量随时间连续变化，瞬时值对应 Φ-t 图像切线斜率的绝对值。
  • 感生电动势来自变化磁场产生的感生电场，即使导体不运动，只要磁通量变化，回路中仍可出现感应电动势。
  • 当回路总电阻 R 恒定时，I=E/R。对整个过程积分可得通过截面的总电荷量 q=N|ΔΦ|/R，与变化持续时间无关。
  • Φ-t 图像斜率决定 E；若斜率过零，感应电动势为零并可能发生方向反转。
  • 多匝线圈要特别区分“单匝磁通量 Φ”和“磁通链 NΦ”，电动势与匝数 N 成正比。

高频标签

E=NΔΦ/Δt瞬时变化率Φ-t 图像斜率q=NΔΦ/R

解题抓手

函数题先写 Φ(t)，再看斜率；只求总电荷量时优先 q=NΔΦ/R，通常不必先求时间函数。
磁通量变化 → 感应电动势 → 电流 → 安培力 → 运动 / 能量

高中物理｜电磁感应专题强化

动生电动势、电路分析与旋转切割

知识只为做题服务：先识别模型，再选主方程
11/43

核心知识与题型

  • 直导体在 B、L、v 两两垂直时，动生电动势 E=BLv；一般情况应取有效长度和垂直于磁场的速度分量。
  • 导体棒可等效为电源：先判断高低电势端，再与外电路做串并联和全电路分析。
  • 绕一端以角速度 ω 转动的导体棒，沿棒速度随半径变化，常用 E=½BωL²。
  • 法拉第圆盘中心到边缘的电动势同样满足 E=½BωR²。
  • 匀速切割且电阻不变时，外力机械功率与回路焦耳功率相等；这是能量检查的重要手段。

高频标签

E=BLv电源等效旋转切割圆盘模型机械功率=电功率

解题抓手

先把“运动导体”当成电源，标出电动势方向，再进行电路分析；转动切割不要机械套 BLv，应对各小段积分或直接用 ½BωL²。
磁通量变化 → 感应电动势 → 电流 → 安培力 → 运动 / 能量

高中物理｜电磁感应专题强化

单棒动力学：无外力、恒力与恒加速度

知识只为做题服务：先识别模型，再选主方程
14/43

核心知识与题型

  • 单棒动力学的主链条是 v → E=BLv → I=BLv/R → F安=BIL=B²L²v/R。
  • 无外力单棒中安培力与速度反向，速度越小安培力越小，棒做加速度逐渐减小的减速运动并趋近静止。
  • 恒力驱动单棒中，外力不变而安培阻力随 v 增大，最终可达到 F外=F安 的终端匀速。
  • 斜轨下滑模型把重力沿轨道分力作为恒力，终端速度由 mg sinθ=B²L²v/R 决定。
  • 若题目要求棒做恒加速度运动，则外力必须随速度增大而增大：F外=ma+B²L²v/R。

高频标签

阻尼单棒恒力单棒终端速度恒加速度维持力

解题抓手

瞬时量用牛顿第二定律；终态先抓“加速度=0”；全过程热量优先能量，避免硬解变加速。
磁通量变化 → 感应电动势 → 电流 → 安培力 → 运动 / 能量

单棒能量、电荷量、位移与冲量

知识只为做题服务：先识别模型，再选主方程
17/43

核心知识与题型

  • 导体棒位移 x 造成回路面积变化 Lx，若 B、L、R 恒定，则通过回路的电荷量 q=BLx/R。
  • 安培力冲量 J安=∫BILdt=BL∫Idt=BLq，可把“电荷量”与“动量变化”直接连接。
  • 无外力阻尼单棒最终静止时，初动能全部转化为回路焦耳热。
  • 若回路有多个电阻串联，总热量按各电阻阻值比例分配；因为各元件电流相同、通电时间相同。
  • 恒力终端匀速时，外力功率 Fv 等于焦耳功率 I²R，常用作结果自检。

高频标签

焦耳热q=BLx/RJ安=BLq功能关系动量定理

解题抓手

问位移/电荷量先想 q=BLx/R；问速度变化/冲量先想 BLq=Δp；问全过程热量优先能量守恒。
磁通量变化 → 感应电动势 → 电流 → 安培力 → 运动 / 能量

题目 3 · 焦耳热分配

磁铁运动使铜管中磁通量变化，产生涡流；涡流磁场阻碍磁铁相对铜管的运动，形成向上的电磁阻力。减少的机械能主要转化为铜管中的焦耳热。
题目 2 · 开槽对涡流影响
把完整金属板沿运动方向开出许多狭槽后，再让它穿过磁场。与完整板相比，电磁阻尼通常如何变化？
解析
开槽破坏了大尺度涡流的闭合路径，使涡流显著减小，因此安培阻力减弱，电磁阻尼变小。

核心知识与题型

  • 自感电动势总是阻碍线圈自身电流的变化：通电时阻碍增大，断电时阻碍减小。
  • 对理想电感而言，线圈电流不能瞬间突变；判断开关瞬间状态时先抓“线圈原电流能否立即改变”。

  • 串并联自感题先标出开关动作前的稳态电流方向，再在动作瞬间保持电感支路电流方向不变。
  • 平均自感电动势大小可用 E_L=L|ΔI|/Δt；断电火花、灯泡闪亮等现象来自较大的自感电动势。

题设

水平光滑平行导轨间距为 L，左端接定值电阻 R。质量为 m、电阻为 r 的导体棒垂直放在导轨上。匀强磁场 B 垂直导轨平面向里。棒初速度为 0，从 t=0 起受到恒力 F 向右作用。经过时间 t，棒向右移动距离 x，速度变为 v。

① 这一过程中通过回路的电荷量 q；
② 安培力的冲量，并写出 F、t、x、v 之间的关系；
③ 回路产生的总焦耳热，以及电阻 R 上产生的热量。
核心特点：速度在变，I 与 F安 都不是常量；但 q、安培力冲量和总热量仍能用积分关系直接求。

补充 · 动量
板书对应：④ 动量
单棒切割母题｜通法一

电荷量 + 动量定理：不用解变加速

先把 ∫I dt 变成位移，再把安培力冲量变成 BLq
42/43
STEP 01 · 瞬时电流
E = BLv，  I = BLv/(R+r)
棒速度变化，所以 I 随时间变化；不能直接用 I·t 代替电荷量。
STEP 02 · 电荷量
q = ∫I dt = [BL/(R+r)]∫v dt = BLx/(R+r)
关键替换：∫v dt = x。于是电荷量只由位移决定，与具体的 v-t 变化细节无关。
STEP 03 · 安培力冲量
J安 = ∫BIL dt = BLq = B²L²x/(R+r)
这就是板书里“F安 t → BLq”的严格写法：变力过程要写积分。
板书主结论｜动量定理

对导体棒沿水平方向列动量定理

Ft − J安 = mv
Ft − B²L²x/(R+r) = mv
恒力的冲量推动棒增速，安培力冲量始终阻碍运动。
题目问 q / x：
优先用 q=BLx/(R+r)。
题目问冲量 / 速度：
优先用 BLq=Δp 的桥梁。
考场模板：一看到“单棒 + 全过程 + 位移 / 电荷量 / 动量”，先写 q=BLx/R总，再写 J安=BLq。

补充 · 能量
板书对应：③ 能量
单棒切割母题｜通法二

能量 + 焦耳热分配：直接求热量

安培力做负功的绝对值，就是回路中产生的总焦耳热
43/43
STEP 01 · 动能定理
WF + W安 = ½mv²
恒力 F 做正功 W_F=Fx；安培力做负功。
STEP 02 · 电磁能量转化
W安 = −Q总
Q总 = Fx − ½mv²
导轨光滑，没有摩擦耗散，因此损失的机械功全部转化为回路焦耳热。
STEP 03 · 串联电阻热量分配
QR : Qr = R : r
QR = [R/(R+r)](Fx − ½mv²)
收束｜四式模板

这道母题最值得记住的 4 个式子

① E = BLv，I = BLv/(R+r)
② q = BLx/(R+r)
③ J安 = BLq = B²L²x/(R+r)
④ Fx = ½mv² + Q总
顺手得到终端速度：若磁场与导轨足够长，最终 F=F安，所以 v终=F(R+r)/(B²L²)。此时 Fv=I²(R+r)，机械功率全部转化为焦耳功率。
